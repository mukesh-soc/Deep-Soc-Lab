## 2. Purpose

This detection identifies PowerShell process activity on monitored Windows endpoints.

PowerShell is a legitimate Windows administration and automation tool, but it can also be used during attack execution.

The purpose of this detection is to provide visibility into PowerShell process creation and allow the SOC analyst to investigate the surrounding process context.
