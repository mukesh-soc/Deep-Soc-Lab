## 2. Objective

The objective of this investigation was to validate the SentinelX SOC telemetry pipeline by generating a controlled PowerShell process-creation event on the Windows endpoint.

The test was designed to confirm that:

1. Sysmon records process creation.
2. The Wazuh Agent collects Sysmon events.
3. Wazuh Manager receives the telemetry.
4. Wazuh detects the activity.
5. The event appears in Wazuh Threat Hunting and Alerts.
6. The activity can be mapped to MITRE ATT&CK.

---

## 3. Detection Scenario

A PowerShell process was intentionally launched on the Windows endpoint during a controlled SOC laboratory test.

The test command was:

powershell.exe -NoProfile -Command "Get-Process | Select-Object -First 5"
