📄 Full Technical Brief View
PHASE 1

Isolated Virtual SOC

Configured isolated VirtualBox LAN hosting Windows 11 endpoint with Sysmon, Ubuntu SOC server with Wazuh & Zeek, and Kali Linux attacker node.

PHASE 2

Telemetry & Normalization

Built Python ingestion pipeline normalizing heterogeneous logs (Zeek TSV, Wazuh JSON, Sysmon EID 1 & 10) into Elastic Common Schema (ECS).

PHASE 3

MISP & Detection Correlation

Created PyMISP integration. Validated positive threat intel match using controlled IOC 192.0.2.123. Mapped Sigma rules to MITRE ATT&CK matrix.

PHASE 4

Zero-Trust 2FA & Fullstack

Engineered full production platform with RFC 6238 TOTP 2FA, QR enrollment, SOAR playbooks, interactive Astro + Flask architecture, and Docker deployment.
